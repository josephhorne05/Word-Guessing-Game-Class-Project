Word-Guessing-Game-Class-Project


  Description of what the code does: This program implements an interactive
   word guessing game. At the start of the game, one of ten possible word-set 
   files is chosen at random. Each file contains a list of
   words along with the point values assigned to each word.
  -The user has 10 total guesses to guess words from the selected file. For each round,
   the program displays a scrambled version of all possible letters along with several
   hint words showing only vowels. The user earns points for each correct guess and loses
   one guess for each incorrect attempt. The game ends when the user guesses all words,
   runs out of guesses, or chooses to quit by entering "q".
   -Throughout the game, the program keeps track of correct guesses, wrong guesses, and
   the user’s total score, updating the display after each round.
